# Z1 运行入口仅面向真机

状态：已确认，2026-10-25。

Z1 当前设计只考虑真实机械臂。单臂和双臂启动固定连接官方 MCU UDP 通信，移除仿真后端、`backend` 选择参数、独立仿真演示程序及依赖该后端的动力学仿真探针。旧的后端参数必须报错，避免旧启动命令的含义被静默改变。

`hardware_validated` 仍默认 false；完成固件、控制方式、模型和参数的现场确认后，才显式设为 true。该条件控制是否允许连接，不替代实际验收。连接失败或握手失败直接退出；连接成功后仍处于 Disabled，需显式 ENABLE。

控制算法和通信的软件契约继续由合成反馈及仅绑定本机地址的 MCU 协议夹具验证。测试夹具不安装到 SDK，不作为 ROS 启动模式，不计算被控机械臂的动力学。真实的跟踪、停止、负载和阻抗性能由真机测量确认。

已有仿真实验输出保留为历史记录，不能作为当前功能说明或真机验收依据。当前运行说明以 [README](../../src/z1_ros/README.md)、[接口契约](../../src/z1_ros/INTERFACES.md)和[需求基线](../../src/z1_ros/REFACTOR_REQUIREMENTS.md)为准。
