# 机械臂采用独立控制内核和 ROS 1 接口

状态：已确认。

机械臂重构采用独立控制内核，由 ROS 1 适配层提供 launch/topic 接口。模型解算、运动生成及执行控制不依赖 ROS；外部适配负责消息转换、参数装配和状态发布。

这样既能重构现有机械臂控制链路，也能继续接入已经逐个重构的 ROS 1 组件。相比本轮迁移 ROS 2，这一方案不要求同时处理其他组件的框架迁移；相比完全独立的 SDK，它保留项目既定的组件 topic 接口与统一 launch 编排方式。未来可以增加 ROS 2 适配，但不属于本轮交付。

本决定不确定官方控制器或 MCU 通信代码的保留范围，也不承诺内核采用某一种硬件控制模式；这些边界分别确认。需求见 [机械臂重构需求](../../src/z1_ros/REFACTOR_REQUIREMENTS.md)。
