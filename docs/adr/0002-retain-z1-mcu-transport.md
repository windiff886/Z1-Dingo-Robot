# 重写控制内核，暂保留官方 MCU 通信适配

状态：已确认；独立链接与真实 UDP 回环已验证，真机固件与执行模式待现场验收。

本轮重写机械臂模型解算、运动生成和执行控制，暂时保留官方 Z1 MCU UDP 通信适配及其必要动态库依赖。旧控制状态机和 SDK 本机 UDP 中转不属于目标控制链路，下位机固件不在本轮重写范围。

这一选择将控制架构重构与底层协议重写分开。可读头文件提供了通信接口及部分报文结构，但初始化握手、版本差异与异常处理的完整实现并未提供源码；相比同时重写协议，先复用通信适配可以集中验证新的运动与控制行为。代价是本轮仍保留对官方动态库及其 ABI 的依赖。

实施前必须验证通信适配能够脱离旧控制状态机独立使用。若验证失败，需要重新确认边界，不自动恢复完整旧控制器，也不自动扩大为协议重写。详细要求见 [需求文档](../../src/z1_ros/REFACTOR_REQUIREMENTS.md)。

首轮离线验证可独立链接并运行官方 IOUDP 的模拟端口路径，但当前库的 `sendRecv` 返回值不能报告新反馈。生产适配已补足有效接收事件与测量时龄，真实固件验证仍在现场接管门槛中；此结果不改变当前替换边界。证据见 [通信预检](../../src/z1_ros/tools/transport_preflight/README.md)。

实施选择：保留 IOUDP 的初始化与编解码，在 UdpPort 套接字层补充有效接收事件、主机接收时间、来源/长度检查和有界接收。实际加载二进制按指纹校验，公共模型/控制类型不含官方类型。生产观察层与内存预检分开，移除旧控制器、SDK 中转和 MoveIt 链路。未重写 MCU 协议或恢复旧 FSM。

代价：观察层仍绑定官方类布局与 ELF 符号调用 ABI；厂商库更换必须重新验证。其宿主接收时间不是固件采样时间。具体实现和验证见 [实施记录](../../src/z1_ros/IMPLEMENTATION_REPORT.md)。
