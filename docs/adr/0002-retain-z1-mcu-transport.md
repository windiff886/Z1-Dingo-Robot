# 重写控制内核，暂保留官方 MCU 通信适配

状态：已确认；独立链接与 UDP 回环已验证。

机械臂模型解算、运动生成和执行控制由主机实现，MCU UDP 通信使用官方动态库。

这一选择将控制架构重构与底层协议重写分开。可读头文件提供了通信接口及部分报文结构，但初始化握手、版本差异与异常处理的完整实现并未提供源码；相比同时重写协议，先复用通信适配可以集中验证新的运动与控制行为。代价是本轮仍保留对官方动态库及其 ABI 的依赖。

通信适配可以独立链接并通过协议夹具测试。详细要求见 [需求文档](../../src/z1_ros/REFACTOR_REQUIREMENTS.md)。

官方库的 `sendRecv` 返回值不能报告新反馈。生产适配通过套接字事件记录有效接收和测量时龄。证据见 [通信预检](../../src/z1_ros/tools/transport_preflight/README.md)。

实施选择：IOUDP 负责初始化与编解码，UdpPort 套接字层提供有效接收事件、主机接收时间、来源/长度检查和有界接收。公共模型/控制类型与官方通信类型分别定义。

代价：观察层仍绑定官方类布局与 ELF 符号调用 ABI；厂商库更换必须重新验证。其宿主接收时间不是固件采样时间。具体实现和验证见 [实施记录](../../src/z1_ros/IMPLEMENTATION_REPORT.md)。
