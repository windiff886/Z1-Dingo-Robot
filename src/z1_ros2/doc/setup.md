# Z1 ROS2 Setup

本目录保留 ROS1 `setup.md` 的文档位置，用于说明 ROS2 Z1 栈的安装与运行约束。

关键包映射：

- `z1_controller` -> `z1_controller_ros2`
- `z1_hw` -> `z1_hardware`
- `z1_dual_moveit_config` -> `z1_dual_moveit_config`
- `z1_rviz` -> `z1_rviz`
- `z1_examples` -> `z1_examples`

推荐工作区初始化后执行：

```bash
source install/setup.bash
```
