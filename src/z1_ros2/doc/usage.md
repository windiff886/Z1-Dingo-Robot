# Z1 ROS2 Usage

本目录保留 ROS1 `usage.md` 的文档位置，用于记录 ROS2 下的等价入口。

常用入口：

- 双臂真机：`z1_bringup/launch/z1_dual_bringup.launch.py`
- 双臂 MoveIt：`z1_dual_moveit_config/launch/move_group.launch.py`
- RViz 查看模型：`z1_rviz/launch/view_model.launch.py`
- RViz 查看机器人：`z1_rviz/launch/view_robot.launch.py`
- 示例源码：`z1_examples/examples/`
