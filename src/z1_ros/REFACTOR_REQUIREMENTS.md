# Z1 机械臂重构需求与实现基线

当前软件实现范围包括独立 C++ 控制内核、ROS 1 topic/launch、官方 MCU 通信适配、有限目标、预计算定时轨迹、MoveL/连续过点、两类流式跟踪及笛卡尔阻抗。用户已授权实施；下述行为作为当前实现基线。软件验证记录见 [IMPLEMENTATION_REPORT.md](IMPLEMENTATION_REPORT.md)。真机参数与固件行为仍需现场验证。

## 1. 组件边界

- 单臂实例只负责自己的模型、运动生成、执行和反馈；左右臂运行同一程序的两个独立进程。
- 外部通过 ROS 1 topics 接入，launch 负责配置和编排。内核不使用 ROS 消息、参数服务器或 ROS 时间。
- 不恢复全身 API，不实现整机遥操、双臂协同、跨臂或动态环境碰撞检查。
- 重写上位机控制；保留官方 `IOUDP` 的 MCU 握手、报文转换及必要动态库，不改下位机固件。
- 当前设计仅面向真机。运行入口固定使用 MCU 通信，不提供仿真后端、后端切换或自动运动演示；单元测试可注入合成反馈，通信测试可使用本机 UDP 协议夹具。
- 主要参考官方 libfranka 的执行、错误和阻抗控制契约；franky 补充在线目标管理。不是移植 Franka 协议或承诺 Franka 的 1 kHz 性能。资料见 [SDK_REFERENCE_RESEARCH.md](SDK_REFERENCE_RESEARCH.md)。

```text
每臂 ROS 1 topics
  ↕ z1_topic_node：消息、参数、发布
独立控制内核：Pinocchio + Ruckig/预计算样条 + Coal + 模式/故障管理
  ↕ McuTransport：官方 IOUDP + 可观测的 UDP 套接字
Z1 MCU
```

| 能力 | 实现及行为 |
| --- | --- |
| 模型 | 六轴固定基座 URDF；FK、雅可比、阻尼最小二乘 IK、RNEA 和 ABA |
| 有限关节目标 | 六个关节角；Ruckig 同步关节轨迹；执行前检查完整参考轨迹 |
| 有限末端目标 | 基座系 TCP 位姿；以保持姿态为 IK 初值，求逆解后执行关节轨迹；不承诺 TCP 直线 |
| 已定时关节轨迹 | 完整 q/v/a 路点与相对时间；预计算 C2 五次样条，严格保留时间或显式全局伸缩；500 Hz 直接采样 |
| 关节连续过点 | 自动安排路点时间和受限内部速度，首尾静止；同方向路点通常以非零速度通过，反向或停顿处可减速/停止 |
| 笛卡尔路径 | MoveL 平移直线与 SO(3) 姿态插值；多点可逐点停止或 C2 圆滑过渡；离线连续 IK、关节样条拟合和全局重定时 |
| 流式关节目标 | 最新合法位置目标更新 Ruckig；不排队执行旧帧 |
| 流式末端目标 | 世界对齐雅可比和旋转对数误差；阻尼差分 IK、关节速度限制、Ruckig 速度平滑及制动路径检查 |
| 笛卡尔阻抗 | 直接跟踪笛卡尔平衡位姿及目标速度；关节参考用于运动边界和几何检查；对角刚度/阻尼支持在线平滑更新 |
| 碰撞 | 自碰撞和配置的固定盒状结构；Coal 距离查询、轨迹验证、制动提前量；危险有限目标拒绝，运动中停止 |
| 夹爪 | 官方握手确认存在后，提供基本位置目标及真实 q/dq/tau 反馈；无夹爪时拒绝命令 |
| 启动 | 仅连接真机 MCU，默认未验收时拒绝连接；验收后连接仍默认失能；两臂参数、端口、关节名和 TF 名分别配置 |
| 诊断 | 有效反馈序号、接收时龄、模式、停止原因、碰撞对/距离、模型配置指纹、计算耗时、循环周期和超期次数 |

当前已接收上层已定时的多点轨迹，并提供原生末端直线和连续过点。标定、示教/回放应用工具、MoveC 圆弧、主动绕障及 ROS 2 适配仍未实现。已有路径接口可供上层示教或回放工具调用，但本轮没有交付相应应用。仿真不属于当前设计范围。

## 3. 模型与算法约束

### 3.1 模型

- 原厂六轴几何、轴方向、位置限位和惯性来源保留；主关节必须按 `joint1..joint6` 排列。
- 默认基座为 `link00`、TCP 为 `tool`。可通过 URDF/配置调整工具安装、工具质量/惯性、基座系重力和固定结构。
- `link01`、`link05` 补充简化碰撞盒；工具使用固定保守包络，覆盖夹爪张合，不加入第七个主臂自由度。
- 新增工具几何和 0.25 kg 惯性为工程初值，必须按实际夹爪/工具/负载核实；不认定为厂商标定值。
- 每个主连杆及工具需要 collision 描述；检查配置中的排除对、固定结构名称、尺寸和变换。缺失几何/错误引用启动失败。
- `fixed_boxes` 默认空，因为仓库无法确定实际支架尺寸及安装关系。现场须建模实际固定结构；空列表不提供支架/底盘防护。
- 模型加载后不可热替换。控制 URDF 与带命名前缀的显示 xacro 需同步修改。安装方向通过基座系重力向量配置，不能默认左右臂安装方向相同。

### 3.2 控制职责

位置跟踪使用计算力矩控制：

```text
a_ctrl = a_ref + Kp (q_ref-q) + Kd (dq_ref-dq)
tau = RNEA(q, dq, a_ctrl)
```

`Kp/Kd` 单位分别为 `s^-2 / s^-1`，不是下位机 PD 增益。六个主关节发送的 MCU `Kp/Kd` 均为零。RNEA 包含惯量、科里奥利和重力，重力不另外叠加。

阻抗使用：

```text
tau = J_LWA(q)^T [K e + D (v_ref-J_LWA(q)dq)] + RNEA(q,dq,0)
```

位置与旋转误差、雅可比和速度使用相同基座对齐坐标；旋转误差为 `log(R_ref R_actual^T)`。不对欧拉角直接相减，不读取或估计外力。补偿包含模型中的工具负载，所有主臂力矩受绝对值及变化率限制。刚度/阻尼在保持或阻抗状态接收，阻抗运行中按一阶滤波平滑更新。

无需力传感器不等于已验证真机阻抗性能。正式驱动前须确认 Z1 固件允许该力矩控制方式、主关节零增益含义及补偿职责。

### 3.3 轨迹与路径

- 动态目标流继续使用时间线、短时预测及在线 Ruckig，允许上层持续修订尚未知的目标；完整定时轨迹使用单独入口，准备完成后按单调时钟直接采样，不再进行第二次在线整形。
- 定时轨迹使用分段五次 Hermite，位置、速度和加速度在节点连续。省略内部速度时用受限相邻斜率估计，省略加速度时取零；显式给出的导数用于端点条件。
- 准备阶段通过分段多项式导数根验证关节位置和 v/a/jerk 极值。严格模式超限即拒绝；重定时模式只允许全局放慢，保持关节路径形状并相应缩放导数，不能修复位置越限或碰撞路径。执行入口要求首尾静止。
- MoveL 在笛卡尔路径上离线求连续 IK 分支，再拟合关节样条；默认在每段 9 个检查点验收 0.1 mm 平移、1 mrad 旋转误差，超差加密，最多 5 轮。该验收是有限采样的模型参考验证，不是连续区间数学误差界或真机精度承诺。
- 多点路径的零 blend 半径逐点停车；正半径在转角附近裁剪并 C2 圆滑连接，不精确经过中间点。当前全局时间伸缩并非时间最优，圆滑路径不保证完成更快。
- 路径构造和全段检查位于提交线程，ROS 通过独立规划回调队列接入，不占用 500 Hz 控制线程或持有控制锁。

### 3.4 碰撞与停止

- 运动学和碰撞使用同一模型。visual 网格不能代替 collision 几何。
- 有限目标先验证 Ruckig 或预计算样条实际生成的整段参考轨迹及关节位置极值；失败或验证预算耗尽则拒绝。
- 距离查询采用自适应步长：依据模型半径上界、当前关节速度和最大加速度，保守约束相邻采样之间的几何运动。不是仅检查终点或固定稀疏采样。
- 模型半径上界在加载时计算并与配置核对。检查数量和耗时均有预算，失败不解释为无碰撞。
- 执行时检查实际测量状态和候选参考的制动轨迹，间距加入实际与参考关节偏差的保守包络。候选步不能维持可检查的制动路径时，放弃候选步，使用上一参考状态生成减速停止。
- 达到警告距离开始停止；实际状态进入硬间距或设备/反馈/计算故障时失能并锁存错误。
- 阻抗停止从实际 q/dq 生成停止参考，清除旧位姿目标，转入计算力矩保持；力矩仍限幅/限变化率，不继续向危险旧目标施力。
- 停止后保持必要的模型支撑力矩；失去有效反馈时不能执行可靠的闭环受控停止，发送被动力矩命令。被动命令不是固件已完成停止的确认，MCU 看门狗和硬件急停须现场核实。
- 几何验证保护的是所建模的参考运动。受控停止的实际制动能力、跟踪偏差、通信延迟和工具几何都必须真机测量；软件算法不构成任意物理状态下的防撞保证。

## 4. 命令与状态规则

详细消息和 topics 见 [INTERFACES.md](INTERFACES.md)。

| 场景 | 本轮规则 |
| --- | --- |
| 启动 | Disabled；有效测量、足够几何间距且静止时显式 ENABLE 才进入 Holding |
| 有限目标 | 只在 Holding 接收；运动中忙时拒绝，不抢占、不排队；合法的新正整数 ID 必须递增 |
| 模式切换 | 先 STOP、等待 AwaitResume，显式 HOLD 回到 Holding 后再选择模式 |
| 流式跟踪 | 显式进入对应模式，使用状态中的 session_id 和递增 sequence；只保留最新合法目标 |
| 输入过期 | 两类流式与阻抗参考超时均减速停止，旧目标失效，进入 AwaitResume |
| 显式恢复 | RESUME 返回上一次流式模式并生成新 session_id；需新的有效目标；停止前和停止期间帧不回放 |
| 不继续旧模式 | AwaitResume 下可显式 HOLD 转为 Holding，再下发有限目标或选择新模式 |
| 硬件/反馈故障 | Fault 锁存；恢复有效测量、静止和间距后 RESUME 仅回到 Disabled；再 ENABLE，不自动恢复运动 |
| DISABLE | 直接被动输出；不等同于受控停止或硬件急停 |
| 成功 | 参考轨迹完成后实际关节误差/速度连续满足容差 100 ms；末端目标与笛卡尔路径同时检查 TCP 位姿误差 |
| 到达失败 | 轨迹结束后超过 settle_timeout 仍未满足实测容差则失败；IK、轨迹错误不报成功 |
| 夹爪 | Holding 下接收 [-1,0] rad 目标，参考限速 0.4 rad/s；暂只报告接收，不提供虚假的到达事件 |

独立内核用单调时钟处理期限。ROS 层对输入时间戳做过期/未来检查，流式消息必须有非零时间戳，并将源时龄扣除后映射到内核期限；位姿消息 frame_id 必须为该臂基座名，不隐式变换其他 TF 坐标系。

## 5. 通信契约

官方 `IOUDP::sendRecv` 在当前二进制中始终返回 true，即使底层接收失败；不能用此值判断新测量。

新增适配保留官方 MCU 协议，在 UDP 套接字层记录每次发送、有效长度/来源的接收和接收时间。未收到有效新报文不增加序号。静止时 q/dq/tau 不变的新报文仍增加序号。

- 绑定各臂自己的本地端口；MCU 目标端口由官方库固定为 8880。`local_port` 不会传给 MCU 作为控制模式或频率参数。
- 检查来源 IP/端口、报文长度、接收预算和积压上限；拒绝重复本地端口。
- 每次交换前丢弃先前积压，不把旧缓存重新打接收时间；网络复制报文无法彻底识别，因为协议未提供固件采样序号。
- 公共 q/dq/tau 使用真实解码的原始字段，不把官方内部 LPFilter 的重复计算视为新测量。
- V2 错误、连接状态和温度从已接收报文的状态字段核实，避免公开温度数组的字段覆盖问题；V1 没有这些状态字段，不伪造为完整诊断。
- `received_at` 是主机接收时间，不是固件采样时间。ROS 关节消息 header 是发布时刻；状态另含有效接收序号及接收时龄。
- 官方库按 SHA-256 锁定并在启动核实实际加载文件；观察层与其类布局/调用 ABI 绑定。更换库或头文件必须重做协议契约测试。

独立复用、套接字回环及新反馈契约可离线验证；真实固件、关节单位/方向、执行性能不因此自动通过。`hardware_validated` 默认 false，启动会在连接前拒绝；现场完成确认后才显式设为 true。握手失败直接退出，启动成功仍需显式使能。

## 6. 参数与验收

默认周期 2 ms（500 Hz，2026-10-23 更新），不是硬实时或 MCU 同频执行承诺。默认接收预算 1 ms、在线轨迹检查预算 0.5 ms；反馈失效 80 ms、输入失效 200 ms、几何间距 8 mm、警告距离 30 mm，都是可配置工程初值。关节速度/加速度/jerk、力矩、增益、到达容差及查询预算统一见 [control.yaml](z1_bringup/config/control.yaml)。

| 验收内容 | 方法 |
| --- | --- |
| FK/IK/动力学 | 已知姿态重建、不可达拒绝、重力与 ABA 一致性 |
| 运动约束 | 检查参考速度、加速度、jerk 和输出力矩变化率；区分实测到达与规划结束 |
| 定时与连续路径 | 原时间和显式导数保真、分段内部极值、保形重定时、C2 过点、直接采样及不规则周期推进 |
| MoveL 与圆滑转角 | 参考 TCP 轮廓、姿态、任务速度、关节约束、首尾静止、纯旋转及不可达拒绝；分清数值拟合验收与真机误差 |
| 有限碰撞 | 合法端点但中间有固定障碍的轨迹必须拒绝 |
| 两类流式和阻抗 | 模式隔离、持续目标、超时锁存、新 session、新目标要求及停止转换 |
| 反馈异常 | 丢包、错误长度、来源、数值不变的新包、同端口冲突、反馈超时 |
| 双臂 | 两个独立进程、关节/TF 命名分离；一臂退出另一臂继续发布 |
| 软件测试夹具 | 合成反馈验证控制契约，回环 MCU 报文验证真机通信和 ROS 接口；不构成可选运行后端 |
| 构建/安装 | 独立 CMake；ROS 1 消息与节点构建；组件 launch、模型及安装路径 |
| 真机 | MCU 固件/单位/方向、力矩和零增益、负载与安装模型、控制周期与新反馈率、实测停止距离、阻抗响应 |

单元测试和 UDP 回环覆盖软件契约，最后一行只能在实际机器人上完成。现场验收前不把工程默认值称为已验证 Z1 参数。
